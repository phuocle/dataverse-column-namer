Developer productivity tool for Microsoft Power Apps & Dataverse. Runs locally, no external login required.

**Demo Environment:**
- URL: https://make.powerapps.com
- Email: demo@d365icons.onmicrosoft.com
- Password: icons@2018
- Environment: DEMO | Solution: DEMO

**Test Cases:**

Case 1: Pin Environment
- Open popup, click 📍 to pin "DEMO" environment
- Save → Status shows "Active"

Case 2: Customer Column Suffix
- Create column, select Data Type: "Customer"
- Enter Display name: "Primary Customer"
- Schema auto-populates: "primary_customer_customerid"

Case 3: Custom Suffix
- In popup, expand Advanced settings
- Change Lookup suffix to "_lookup"
- Save, create Lookup column
- Schema shows custom suffix "_lookup"

Case 4: Inactive Environment
- Switch to different environment (not DEMO)
- Status shows "Inactive"
- Schema name NOT auto-populated

**Key Features:**
- Auto-generates schema names from display names
- Type-based suffixes (Lookup→_id, Customer→_customerid, Choice→_choice)
- 5 naming conventions (underscore_lowercase, pascalCase, etc.)
- Pin environment safety feature
- Import/Export configuration

**Permissions:**
- activeTab: Detect current environment
- scripting: Inject naming logic
- storage: Save configuration locally

**Privacy:** No data collection. All settings stored locally.
