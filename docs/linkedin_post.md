I'm excited to announce the release of my new browser extension: **Dataverse Column Namer**.

As developers, we spend countless hours creating columns in Dataverse. The most tedious part? Manually typing out the "Schema Name" to match our coding standards (removing spaces, handling casing, adding prefixes...).

So I built a tool to fix that. 🛠️

**Dataverse Column Namer** automatically generates the Schema Name for you in real-time as you type the Display Name.

✨ **Key Features:**
*   **Auto-Naming:** Instant schema generation based on your preferred style (snake_case, PascalCase, camelCase, etc.).
*   **Smart Suffixes:** Automatically appends suffixes based on data type (e.g., `_id` for Lookups, `_date` for DateTimes).
*   **Secure:** Runs 100% locally in your browser. No data leaves your machine.
*   **Safe:** Only activates on environments you explicitly pin.

It’s a simple utility that saves seconds per column—and hours per project.
